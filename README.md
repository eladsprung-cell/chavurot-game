# חבורות – משחק אסטרטגיה

משחק אסטרטגיה בזמן אמת בדפדפן, שבו כל חבורה היא מדינה על מפת העולם.
השחקנים מתחברים עם Google, בוחרים מי הם ובאיזו חבורה הם משחקים, ויחד מרחיבים את שטח החבורה שלהם.

The groups and people come from the "חבורות" app: https://chavurot-d0f68.web.app

## Running it on your computer

You need Node.js 24 and npm 12.

```bash
npm run inst
npm run dev
```

Then open http://localhost:9000
